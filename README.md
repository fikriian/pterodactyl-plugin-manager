# Minecraft Plugin Manager

A Minecraft Plugin Manager Extension for Pterodactyl Panel. Using **[Blueprint](https://blueprint.zip)**.

## Features

- [ ] Working search bar, filters
- [ ] Manage Plugin

## Requirements

- Pterodactyl Panel 1.15.x
- Blueprint Installed

## Installation

1. Download the extension
2. Upload the extension to your server
3. Run `blueprint -i mcpluginmanager.blueprint`
